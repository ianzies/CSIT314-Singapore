# CSIT314 Intelligent Talent Matching Platform

Prototype Flask web application for matching job-seeking candidates with employers.

## Tech Stack

- Python
- Flask
- SQLite
- HTML/CSS
- Werkzeug password hashing

## Setup

```bash
git clone https://github.com/ianzies/CSIT314-Singapore.git
cd CSIT314-Singapore

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```
http://127.0.0.1:5000
